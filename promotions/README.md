# 回响 · 推广素材

本次推广围绕「把微信聊天整理成自己的本地档案」。全部会话、人物、文件和数字均为合成演示内容，不使用真实聊天截图。

- `xiaohongshu.md`：标题、正文、封面与发布建议。
- `video-script.md`：介绍视频的分镜与旁白。
- `reference-easel.md`：参考来源与采用的方法。
- `render_assets.py`：可重复生成封面、图文卡和 1080 × 1920 介绍视频的脚本。
- `narration.ps1`：使用 Windows 本机语音生成旁白，不调用外部语音服务。
- `media/`：视频、封面、图文卡与字幕成品。

官网与 GitHub 发布可直接使用这些材料；小红书正文是待发布稿。账号发布需要实际的平台登录状态，不能把生成素材写成已经发帖。

官网展示的是研发中的档案体验；公开 0.1.0 安装包仍为早期合成摘要演示版。新功能打包发布前，推广稿必须保留这项说明。
