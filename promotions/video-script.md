# 产品介绍视频

画幅：1080 × 1920，30 fps，约 48 秒。绿色与米白品牌色，六个章节，中文字幕与本机合成旁白，无背景音乐。全部界面为合成流程示意，非真实录屏；片尾标明档案版尚未打包公开。

| 时间 | 画面 | 旁白 |
|---|---|---|
| 00–08 | 品牌与散落的聊天 / 照片 / 文件 | 微信里的照片和文件，总要翻很久。回响，帮你整理自己的本地聊天档案。 |
| 08–16 | 个人 / 群聊 / 公众号列表、关注 | 个人、群聊、公众号分开看。最近消息优先，关心的会话可以关注。 |
| 16–24 | 会话图片 / 视频 / 文件标签 | 打开会话，不止能看对话。切换图片、视频和文件，找回分享过的资料。 |
| 24–32 | 媒体分类、搜索、原图筛选 | 媒体库支持搜索、翻页和排序。有可解码的本机原图就优先显示。 |
| 32–40 | 本机目录、5 分钟增量更新 | 档案保存在自己的电脑。应用打开时，每五分钟检查变化，变化的库才更新。 |
| 40–48 | 项目入口与版本边界 | 这是开发中的体验示意。新档案功能尚未打包公开。欢迎来看看回响。 |
